---

## ⚡ Why DataViz Studio?

Cleaning raw datasets manually can be repetitive and time-consuming. **DataViz Studio** automates the tedious data preparation pipeline so analysts and developers can jump straight into data exploration and visualization.

---

## 🛠️ Key Features

- 🧹 **Automated Data Cleaning:** Instantly detects missing values, duplicate records, and improperly formatted headers.
- 📊 **Instant Analytics Dashboard:** Generates high-level metrics including total rows, column counts, and summary statistics.
- 📈 **Interactive Visualizations:** Automatically visualizes categorical distributions and numerical trends.
- 📁 **Seamless CSV Parsing:** Rapid upload, preview, and clean data export capabilities.
